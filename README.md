# Cocos Demo - Tic Tac Toe

Turn-based demonstration project using Colyseus and Cocos Creator 3.8.8.

> **Edgegap fork.** Upgraded to Cocos Creator 3.8.8 and Colyseus 0.17, with one Colyseus server per match on [Edgegap](https://edgegap.com), started by Edgegap's matchmaker. See [edgegap/README.md](edgegap/README.md).

# Running the server locally

From the root of the project:

```
cd Server
npm install
npm start
```
